# AutoFIRE Trading Simulator

실제 장 시간 없이 전체 시스템을 테스트할 수 있는 시뮬레이터입니다.

## 🎯 주요 기능

- ✅ 가상 시세 데이터 생성 (랜덤 변동)
- ✅ 가상 계좌 관리 (매수/매도/손익 계산)
- ✅ 실제 Selector/Portfolio/Strategy 로직 시뮬레이션
- ✅ Discord 알림으로 실시간 진행 상황 확인
- ✅ 익절/손절/강제청산 테스트
- ✅ SELECTION_MODE, STRATEGY_MODE 검증

## 📦 사용 방법

### 1. 빠른 테스트 (권장)

```bash
# 30분만 빠르게 테스트 (약 10초 소요)
docker exec -it autofire-bot python test_simulator.py --fast --minutes 30

# 60분 테스트 (약 20초 소요)
docker exec -it autofire-bot python test_simulator.py --fast --minutes 60
```

### 2. 전체 장 시뮬레이션 (약 3분 소요)

```bash
# 09:00~15:20 전체 (390분) - 오래 걸림!
docker exec -it autofire-bot python test_simulator.py --fast
```

### 3. 옵션 조합

```bash
# 특정 날짜, 하락장 시나리오, 30분 테스트
docker exec -it autofire-bot python test_simulator.py --date 2024-03-20 --scenario downtrend --fast --minutes 30

# 상승장 100분 테스트
docker exec -it autofire-bot python test_simulator.py --scenario uptrend --fast --minutes 100
```

### 4. 명령어 옵션

| 옵션 | 설명 | 예시 |
|------|------|------|
| `--fast` | 빠른 모드 (딜레이 없음) | 필수 옵션 |
| `--minutes N` | N분만 실행 | `--minutes 30` |
| `--scenario` | 시장 시나리오 선택 | `--scenario uptrend` |
| `--date` | 특정 날짜 지정 | `--date 2024-03-20` |

### 5. 시나리오 종류

| 시나리오 | 설명 | 용도 |
|---------|------|------|
| `normal` | 정상 변동 (±3% 이내) | 일반적인 시장 테스트 |
| `volatile` | 고변동성 (±5% 이내) | 급등락 대응 테스트 |
| `uptrend` | 상승 추세 (+5% 목표) | 익절 테스트 |
| `downtrend` | 하락 추세 (-5% 목표) | 손절 테스트 |

## ⚙️ 설정 변경 테스트

`.env` 파일의 설정을 변경하면 시뮬레이터에 즉시 반영됩니다:

```bash
# .env 예시
SELECTION_MODE=AND       # AND 모드 테스트
STRATEGY_MODE=AND        # 모든 전략 일치 필요
TAKE_PROFIT=5.0          # 익절 기준 변경
STOP_LOSS=-1.0           # 손절 기준 변경
```

## 🐛 주의사항

1. **Mock 데이터 한계**
   - 실제 시장 데이터가 아닌 랜덤 생성 데이터
   - 실제 장과 100% 동일하지 않음

2. **간소화된 로직**
   - 실제 Selector/Strategy 대신 Mock 시그널 사용
   - 슬리피지, 체결 지연 등 미반영

3. **테스트 목적**
   - 전체 흐름 검증용
   - 설정 변경 효과 확인용
   - 실제 운영 전 최종 점검용
